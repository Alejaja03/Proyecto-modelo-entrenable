# Proyecto-modelo-entrenable

Funcionamiento del proyecto: Este proyecto permite clasificar y analizar distintas imágenes distribuyéndolas según si especie utilizando un lenguaje de Python y librerías como Keras. El proyecto consta de 3 clasificaciones, Tiburones, medusas y pulpos. La clasificación de imágenes realizada esta con base a una imágenes ya subidas para mejorar el análisis.
